# Projekt-Savepoints und Entwicklungshistorie

Die Dateien in diesem Ordner dokumentieren frühere Projektzustände,
Release-Vorbereitungen, offene Prüfpflichten und Entscheidungen über
Entwicklungszweige. Sie dienen der Nachvollziehbarkeit der Arbeit.

Ein Savepoint ist keine eigenständige aktuelle Veröffentlichung. Aussagen über
einen damaligen lokalen oder ausgewählten Abschluss sind zusammen mit dessen
Voraussetzungen, Residuen und ausdrücklich zurückgestellten globalen oder
physikalischen Fragen zu lesen. Die aktuelle öffentliche Baseline ist separat
im Repository-README und in den Release-Metadaten ausgewiesen.

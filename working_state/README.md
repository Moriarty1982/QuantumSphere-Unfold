# Historische Arbeitsstände

Dieser Ordner bewahrt Zwischenstände, lokale Diagnostik und zugehörige
Auditberichte. Die Versionsnummern benennen den damaligen Arbeitsstand;
sie legen nicht die aktuelle öffentliche Release-Baseline fest.

Insbesondere bleiben offene Voraussetzungen, Obstruktionen und nicht
abgeschlossene OP-Fragen des jeweiligen Savepoints erhalten. Diagnostische
Ergebnisse dürfen nur innerhalb der dokumentierten Modellannahmen verwendet
werden. Für die aktuelle veröffentlichte Baseline gelten die Release-Angaben
im Repository-README und im zugehörigen Zenodo-Datensatz.

# H226 (k440): tauschbrechender Term für den Modulus φ

**Widerlegt.** Kein einfacher Term, der Im- und Re-Sektor unterscheidet, macht φ = 0,0396 zum globalen Minimum der Vakuumenergie. Der Konjugationsterm nur im
geladenen Sektor (α = 2,42 q) macht φ = x zu einem lokalen, stabilen Minimum, das globale liegt bei −0,70; angepasst an die geladenen Leptonen sagt er x_ν = 0,495
voraus (+212σ). Ungleiche kubische Stärke bräuchte das falsche Vorzeichen, ungleiche Spin-1-Stärke wirkt nicht. Python + Wolfram einig.

== 1  Tausch J: z -> i conj(z) ==
  J z - z(i conj b, i conj a) = 0  => (a, b) -> (i conj b, i conj a)
  J^2 = 1: [0, 0]
  C = (1 + J)/2: C^2 - C = [0, 0] ;  |C a|^2 - |C b|^2 = 0  => Bild von C: |a| = |b| (Linie, mu = 1)
  Rang von C als reell-lineare Abbildung auf (a_r, a_i, b_r, b_i): 2 von 4
  Im(e^{-i pi/4} C z) = 0  => C z liegt auf der 45-Grad-Linie (Fixpunktmenge, theta = pi/4 wie H149)
  |mu| unter J: |b/a| -> Abs(a_r)/Abs(b_r) (fuer reelle a, b): mu -> 1/mu wie k297

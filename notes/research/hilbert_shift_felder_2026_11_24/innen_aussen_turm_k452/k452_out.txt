Teil 5: Warum es anhaelt, physikalisch: die Wand zwischen innen und aussen ist eine Sphaere S^(N-1) im Feldraum (N = 2^n).
  Eine Verdrehung in jede Richtung braucht auf der Wand N-1 ueberall von null verschiedene, orthonormale Tangentialfelder
  (ein Rahmen). Kandidat: v_i(x) = e_i x (Linksmultiplikation mit den Imaginaereinheiten). Pruefung auf zufaelligen x der Wand:
  HS(1): Wand S^1: max |<v_i, x>| = 2.8e-17, max |Gram - 1| = 3.3e-16  -> voller Verdrehungsrahmen
  HS(2): Wand S^3: max |<v_i, x>| = 0.0e+00, max |Gram - 1| = 4.4e-16  -> voller Verdrehungsrahmen
  HS(3): Wand S^7: max |<v_i, x>| = 1.1e-16, max |Gram - 1| = 4.4e-16  -> voller Verdrehungsrahmen
  HS(4): Wand S^15: max |<v_i, x>| = 1.1e-16, max |Gram - 1| = 8.4e-01  -> KEIN Rahmen (Richtungen fallen zusammen)

  Radon-Hurwitz: Zahl unabhaengiger, nirgends verschwindender Verdrehungsfelder auf der Wand S^(N-1) = rho(N) - 1
    HS(0): N =   1, Wand S^0  :  0 Felder von  0 noetigen -> voller Rahmen
    HS(1): N =   2, Wand S^1  :  1 Felder von  1 noetigen -> voller Rahmen
    HS(2): N =   4, Wand S^3  :  3 Felder von  3 noetigen -> voller Rahmen
    HS(3): N =   8, Wand S^7  :  7 Felder von  7 noetigen -> voller Rahmen
    HS(4): N =  16, Wand S^15 :  8 Felder von 15 noetigen -> Rahmen fehlt 7
    HS(5): N =  32, Wand S^31 :  9 Felder von 31 noetigen -> Rahmen fehlt 22
    HS(6): N =  64, Wand S^63 : 11 Felder von 63 noetigen -> Rahmen fehlt 52
  Voller Rahmen nur fuer N = 1, 2, 4, 8 (Adams 1960: Hopf-Invariante 1 nur in diesen Dimensionen).

Teil 7: Feldgleichung je Stufe: D = d_0 + sum_i e_i d_i (Cauchy-Riemann / Fueter / Dirac der Stufe), D f = 0.
  Sie ist nur dann eine Wurzel der Wellen-/Laplace-Gleichung (Dbar D f = Laplace f fuer JEDES Feld f), wenn die Linksmultiplikationen
  L_i eine Clifford-Darstellung bilden: L_i L_j + L_j L_i = -2 delta_ij. Pruefung als Matrizen:
  HS(1): max |L_i L_j + L_j L_i + 2 delta_ij| = 0.0e+00  -> Dbar D = Laplace, Feldgleichung erster Ordnung wohlgestellt
  HS(2): max |L_i L_j + L_j L_i + 2 delta_ij| = 0.0e+00  -> Dbar D = Laplace, Feldgleichung erster Ordnung wohlgestellt
  HS(3): max |L_i L_j + L_j L_i + 2 delta_ij| = 0.0e+00  -> Dbar D = Laplace, Feldgleichung erster Ordnung wohlgestellt
  HS(4): max |L_i L_j + L_j L_i + 2 delta_ij| = 2.0e+00  -> Dbar D != Laplace: keine Wurzel der Wellengleichung

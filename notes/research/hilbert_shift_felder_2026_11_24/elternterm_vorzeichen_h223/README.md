# H223 (k437): Elternterm für das Vorzeichen des Zweigwahl-Terms

**Urteil: widerlegt.** Kein natürlicher kubischer Baustein (det W, Tr W³, spurfreie oder reine Spurbausteine) liefert über sein Quadrat unter J das Vorzeichen,
das die Daten verlangen: β₃(J) = 4z(27x + 9y + z), für det W +4, für Tr W³ +36 (falscher Zweig), sonst 0. Bindung an den Spin-1-Term ist ausgeschlossen (α′ wechselt das
Vorzeichen zwischen den Sektoren; Spur und Determinante sehen χ nicht). Nachträglich: Das richtige Vorzeichen kommt nur aus dem J-verbotenen Teil von N². Python + Wolfram einig.

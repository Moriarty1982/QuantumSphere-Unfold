# H204 / k414 — Elter-F₄-Darstellung: bindet eine Darstellung D/B?

**Verdikt: nein** (Kriterium K2). Keine einzelne höhere F₄-Darstellung legt das Verhältnis D/B fest.

Vom Autor gewählte Weggabel (Karte, Option B „Elter-F4-Darstellung prüfen", 27.11. 12:18 UTC), nach H202 (Rest D/B frei) und H203 (Lepton-Sektor bindet nicht).

- Die Ladungs-kovariante l_k²-Operatoralgebra auf dem Farbblock ist **exakt 2-dimensional** ({1, iL_U}, (iL_U)²=1) mit genau zwei minimalen Idempotenten P_up, P_dn. Eine **einzelne** Darstellung erzwingt D/B nur **diskret** {0, +1, −1, ∞}.
- Datenwert D/B = 1,0085 ± 0,0010 liegt **8,5σ** vom nächsten diskreten Wert (+1) entfernt ⇒ eine **zweite** Komponente nötig.
- B (Feldgrad 5) und D (Feldgrad 4) liegen in **verschiedenen** F₄-Tensorgraden ⇒ keine einzelne F₄-Irrep trägt beide. D/B = freie relative Normierung, kein Clebsch–Gordan.
- Bestätigt H202 (Rang 4). Schließt die Elter-Route. **Teilweise nicht blind** (Grad-Trennung aus H201 bekannt; neu: Branching-Lesart + diskret-vs-Daten-Abgleich).

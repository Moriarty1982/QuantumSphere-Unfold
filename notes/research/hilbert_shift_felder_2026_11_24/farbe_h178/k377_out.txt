== H178a: J auf ganz O (U = e7) ==
   J^2 = +1 auf {1, U}: Fehler 0.0e+00;  J^2 = -1 auf e1..e6: Fehler 0.0e+00
   Bilder der Einheiten: J(e0) = +e7; J(e1) = +e6; J(e2) = -e5; J(e3) = -e4; J(e4) = +e3; J(e5) = +e2; J(e6) = -e1; J(e7) = +e0
   J tauscht x0 und xU, erhaelt |c|^2 und N (1000 Zufallselemente): groesste Abweichung 7.1e-15
   Ebene {1, c}, c = e1: J(cos t + sin t c) hat Komponenten nur auf [6, 7] (also auf U und U c): die Ebene wird nicht auf sich abgebildet.
   Folge: Die Abbildung theta -> pi/2 - theta gibt es nur in der Ebene {1, U}.

== H178b: allgemeinstes Potential bis Grad 4, invariant unter SU(3)_c, Konjugation und J ==
   Invarianten eines Elements unter SU(3)_c: x0, xU, q = |c|^2. Konjugation: xU -> -xU. J: x0 <-> xU.
   Grad 2: s = x0^2 + xU^2, q.  Grad 4: s^2, s q, q^2, p = x0^2 xU^2.  Auf N = s + q = 1: V = A q + B q^2 + kappa p + konst. (drei Koeffizienten).
   V(t), t = sin^2 theta: A*t*sin(alpha)**2 + B*t**2*sin(alpha)**4 + kappa*t*(1 - t)*cos(alpha)**2
   stationaer bei t* = (-A*sin(alpha)**2 - kappa*cos(alpha)**2)/(2*(B*sin(alpha)**4 - kappa*cos(alpha)**2)) ;  V'' = 2*B*sin(alpha)**4 - 2*kappa*cos(alpha)**2
   alpha = 0: t* = 1/2 (theta = pi/4, unabhaengig von A, B);  V'' = -2*kappa (Minimum genau fuer kappa < 0)
   d t*/dA = -sin(alpha)**2/(2*B*sin(alpha)**4 - 2*kappa*cos(alpha)**2)  -> fuer alpha != 0 haengt der Winkel von den Koeffizienten ab.
   Urteil H178b: BESTAETIGT (pi/4 ist nur fuer alpha = 0 festgelegt).

# Skala und Sektoren (H168; 26.11.2026)

Frage des Autors: Hängt die Skala mit den Sektoren zusammen? Es könnte beides sein.

**Kurzfassung.** Mit dem Spin-1-Term allein liegt das Minimum für c = 0 bei π/6, für c = 1 bei π/12: der Abstand π/12 ist die Verschiebung zwischen Neutrino-
und Lepton-Phase aus H99. Beide Sektoren liegen um denselben Versatz x = 0,0396 darunter. Eine feste gemeinsame Skala kann den Versatz nicht liefern (im
Neutrinosektor wäre er 10⁻¹²; R = 0,0407, 23σ). Er ist dimensionslos, oder die Skala wächst mit dem Sektor. Unter acht Kandidaten passt nur π/6 − x (blind);
keine native Zahl trifft x (blind).

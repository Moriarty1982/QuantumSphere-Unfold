# Ergebnis H84: Quantenmoden sind bei τ* singulär; der Versatz δ ≠ 0 trägt nur klassisch

Vorab-Notiz `Vorab_Notiz_H84_Quantenmoden_tau_stern.md`, Commit `d2a19f2` (nicht blind). Skript `k199_quantenmoden_tau_stern.py`, Ausgabe `k199_out.json`.

## Ergebnisse (Strahlung, δ = 1, Materie-Gewichte, k = m = 1, τ* = 0,354572)
- **H84a bestätigt:** Die Wronski-Determinante K·(χχ̄′ − χ̄χ′) = i bleibt bis |τ − τ*| = 10⁻⁸ konstant (relative Abweichung 4·10⁻¹⁵ links, 4·10⁻¹⁴ rechts). Weil K bei τ* verschwindet, divergiert χ′ dort wie 1/|τ − τ*|; keine Mode mit dieser Normierung ist regulär.
- **H84b bestätigt:** E·|τ − τ*| → −0,1496 von links und +0,1494 von rechts (Streuung 8·10⁻⁵ bzw. 7·10⁻⁵ auf den letzten drei Dekaden). Die Energiedichte einer Quantenmode divergiert wie 1/|τ − τ*| und wechselt dort das Vorzeichen; ihr Zeitintegral divergiert logarithmisch.

## Folge (wie vorab)
Die Modenauswahl aus H81 gilt nur klassisch: Die eine reguläre Lösung ist reell, eine Quantenmode braucht aber eine komplexe Lösung mit Wronski-Determinante ≠ 0, und die ist bei τ* zwangsläufig singulär. Mit Versatz δ ≠ 0 ist die zweite Lesart quantenmechanisch bei τ* singulär. Für ein Quantenfeld spricht das für δ = 0 (H80), also die Spiegelung um den Urknall. Ob ein endlich schneller Übergang (statt der scharfen Nullstelle von K) das heilt, ist offen.

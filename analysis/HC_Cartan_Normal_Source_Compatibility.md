## Conditional Source Law

Split z into 464 free normal-containing coordinates w and 736 prescribed
tangential coordinates d. The [independent mask audit](HC_Cartan_Source_Cauchy_Jet_Mask.md)
explains the packing: allowed E3 entries need at least two temporal indices,
whereas allowed psi3 entries need at least one. Fixed coordinates mean fixed
increments about the saved germ, not vanishing absolute derivatives.

Writing A_f and A_d for these column sets gives

    J = L_f.T B,
    b(d) = -L_f.T (h0 + A_d d),
    q(d) = J^+ b(d),
    w(d) = -A_f^+ (h0 + A_d d + B q(d)).

This uniquely determines q only when J has rank six AND
(I-J J^+)b(d)=0. The implementation rejects incompatible prescribed data;
least-squares projection alone is not accepted. Higher lifts still differ
by ker(A_f), so uniqueness of q is not uniqueness of all higher derivatives.
The displayed w is minimum-norm in the declared coordinates, not physically
selected. The remaining linear compatibility map on d has numerical rank
126; this is a finite-jet matrix rank, not a physical constraint count.
The source-law matrix is 6 by 736. In particular, q=0 is not postulated:
the near-zero value at d=0 concerns increments about the saved compatible jet.
